# Draft from Source Pack

Draft directly from the supplied material.

## Workflow

1. identify the objective, audience, and artifact type
2. identify the source basis
3. draft from that material without inventing support
4. flag missing evidence instead of filling gaps with guesswork
5. return a serious first pass, not a placeholder
