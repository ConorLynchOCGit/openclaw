# Critique and Revise

Improve a draft through explicit review criteria.

## Review Criteria

- instruction following
- clarity
- structure
- tone fit
- evidence fidelity
- brevity where appropriate

## Workflow

1. identify the weakest parts of the draft
2. revise against the review criteria
3. remove filler and repetition
4. preserve supported claims and qualifiers
5. return the improved draft
