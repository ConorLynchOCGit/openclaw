# Memory Middleware Skills

This directory holds companion runtime skills and procurement guidance for the
`memory-middleware` extension.

Immediate posture:

- Skill Vetter is mandatory before any third-party skill is treated as approved
  for normal use.
- `self-improving-agent` is the first intended learning-oriented external
  skill.
- Both are accelerators and not the canonical memory substrate.
- The existing repo memory architecture remains authoritative until the custom
  middleware is implemented.

Procurement governance:

- Follow `docs/memory-system/SKILL_PROCUREMENT.md` as the canonical workflow
  for externally sourced skills.
- Use `skill-procurement/SKILL.md` when evaluating ClawHub, GitHub, or other
  imported skills for the memory-system effort.
- Follow `docs/memory-system/SELF_IMPROVING_AGENT_INTEGRATION.md` for the
  allowed role and guardrails of `self-improving-agent`.
- Do not install, enable, or treat any third-party skill as approved for
  normal use until Skill Vetter findings are recorded and the documented
  approval state is reached.
