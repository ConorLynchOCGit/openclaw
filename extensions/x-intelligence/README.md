# X Intelligence

Bundled, read-only X source operations for OpenClaw research agents.

## Ownership

- This plugin owns official X API transport, bounded source hydration, mutable
  content cache, and immutable acquisition/compliance receipts.
- The bundled `xai` plugin owns Grok semantic `x_search`.
- X Researcher owns analytical method and source interpretation.
- Agency Data owns normalized marketing observations and derived analytics.
- Business Ops owns recommendations and operator-approved learning.

The plugin replaces the workspace `x-discourse-collector` and its private n8n
transport after migration and one stabilization window. It is not a fallback or
a second permanent X path.

## Tools

- `x_posts`: bounded post search and exact post/conversation hydration.
- `x_counts`: equivalent-window recent or archive counts.
- `x_users`: account discovery, stable identity, and relationships.
- `x_timelines`: bounded authored-content panels.
- `x_trends`: broad or personalized candidate-topic discovery.
- `x_metrics`: public metrics, separately authorized owned metrics, and bounded
  project usage readback.

No tool can publish, edit, delete, engage, follow, message, schedule, purchase
credits, broaden scopes, or enable recurring collection.

## Evidence And Retention

Immutable manifests contain IDs, URLs, hashes, citations, metrics, request and
method metadata, cost/resource receipts, and bounded errors. Mutable post and
profile content is cached for at most 24 hours and must be rehydrated before
later display or reuse. Business Ops stores refs, IDs, claims, interpretations,
and limitations rather than copied source objects.
