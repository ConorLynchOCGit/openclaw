# Draft from Source Pack

## Purpose

Turn supplied notes, bullets, transcripts, or research artifacts into a strong first-pass draft without inventing support.

## Use When

- the source material already exists
- the task is primarily drafting, not fact-finding
- the user wants a memo, brief, article section, note, or structured prose artifact

## Workflow

1. identify the source basis
2. identify the target audience and artifact type
3. draft directly from the material provided
4. flag missing support instead of filling gaps with guesswork
5. leave the result readable enough to serve as a serious first pass
