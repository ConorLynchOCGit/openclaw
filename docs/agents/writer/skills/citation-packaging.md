# Citation Packaging

## Purpose

Turn sourced research material into a readable deliverable while preserving claim-linked attribution.

## Use When

- the draft depends on external evidence
- the user wants a memo, brief, or summary that remains traceable to sources

## Workflow

1. identify which claims need explicit support
2. keep source-linked notes attached to those claims
3. remove unsupported embellishment
4. preserve uncertainty where the evidence is mixed
5. package the result so it reads cleanly without losing traceability
