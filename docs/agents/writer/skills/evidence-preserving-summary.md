# Evidence-Preserving Summary

## Purpose

Summarize source material while preserving qualifiers, uncertainty, and source-backed boundaries.

## Use When

- the user wants a summary of long or dense material
- the source contains mixed-confidence claims
- the summary must remain faithful to the evidence

## Workflow

1. identify the source basis
2. extract the core findings
3. preserve important qualifiers and uncertainty
4. remove drift, hype, and false precision
5. make unresolved points explicit
