# Critique and Revise

## Purpose

Improve a draft through an explicit review pass rather than vague polishing.

## Use When

- a draft exists but needs improvement
- the request is about clarity, structure, tone, or usefulness
- the output should move closer to final-draft quality

## Review Criteria

- instruction following
- clarity
- structure
- tone fit
- evidence fidelity
- brevity where appropriate

## Workflow

1. identify the weakest parts of the draft
2. revise against the review criteria
3. remove filler and repetition
4. preserve supported claims and qualifiers
5. return the improved draft, not just commentary
