# Rewrite for Audience

## Purpose

Adapt the same underlying content to a new audience, tone, or format while preserving meaning.

## Use When

- the core content is already known
- the main task is changing tone, density, or presentation
- the user wants executive, technical, customer-facing, or operator-oriented variants

## Workflow

1. identify the original content
2. identify the target audience and tone
3. rewrite for that audience
4. preserve meaning and important caveats
5. note any unavoidable tradeoff introduced by compression or simplification
