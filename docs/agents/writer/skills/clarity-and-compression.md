# Clarity and Compression

## Purpose

Improve readability by tightening prose, simplifying wording, and removing repetition without damaging meaning.

## Use When

- the draft is too long, too dense, or too repetitive
- the main need is stronger clarity rather than new content

## Workflow

1. identify repetition and weak phrasing
2. shorten where possible
3. simplify without flattening important nuance
4. preserve claims, caveats, and structure
5. return cleaner prose, not just editing notes
