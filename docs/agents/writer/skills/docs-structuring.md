# Docs Structuring

## Purpose

Turn rough notes, bullets, or fragments into a coherent document structure and usable draft content.

## Use When

- the task is creating a docs page, runbook, audit note, migration note, or structured memo
- the material exists but the organization is weak

## Workflow

1. identify the target document type
2. propose a clean hierarchy
3. draft the key sections
4. surface missing inputs explicitly
5. keep the result easy to extend later
