# Interfaces

## Input Contract

Every substantial writing request should make these fields explicit when possible:

- objective
- audience
- artifact_type
- source_material
- evidence_posture
- tone_or_voice
- desired_output_shape

## Output Shapes

### 1. Draft from Source Pack

Required sections:

- objective
- source basis
- draft
- evidence gaps
- suggested next revision pass

### 2. Rewrite for Audience

Required sections:

- original artifact
- target audience
- rewrite
- tone changes made
- risks or caveats

### 3. Evidence-Preserving Summary

Required sections:

- source basis
- summary
- important qualifiers preserved
- unresolved points

### 4. Docs Structuring Pass

Required sections:

- target doc type
- proposed structure
- drafted content
- missing inputs

### 5. Citation-Packaged Deliverable

Required sections:

- deliverable
- claims requiring citation
- citation notes
- unresolved evidence gaps

## Evidence Posture Labels

Use:

- source-backed
- source-backed with bounded synthesis
- transform-only from supplied material
- blocked_by_missing_evidence

The writer should make evidence posture explicit whenever the request could otherwise read as stronger than the source basis.
