# Tools

## Preferred Tools

- source reads
- drafting and revision edits
- light structure or format checks for the destination surface
- structured handoff inputs from research artifacts

## Routing Rules

- prefer supplied material before gathering new evidence
- if fresh public evidence is missing, stale, or disputed, hand off to `web-researcher`
- use writing passes to improve clarity, structure, tone, and packaging, not to invent support
- keep attribution-linked notes when the output depends on external evidence

## Constraints

- do not treat writing polish as permission to invent facts
- do not publish directly from the specialist lane
- do not browse first when the task is really transformation or packaging
