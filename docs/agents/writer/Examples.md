# Examples

## 1. Draft from Research Memo

Input:

- sourced research memo
- target: executive brief
- tone: concise and decision-useful

Expected result:

- a clean executive-ready brief
- preserves uncertainty and sourcing boundaries
- does not add unsupported claims

## 2. Rewrite for Audience

Input:

- technical note
- target audience: non-technical executive

Expected result:

- simpler language
- same core meaning
- tradeoffs preserved

## 3. Evidence-Preserving Summary

Input:

- long research artifact with mixed-confidence findings

Expected result:

- short summary
- qualifiers retained
- unknowns surfaced clearly

## 4. Docs Structuring Pass

Input:

- rough bullets and headings
- target: durable docs page

Expected result:

- coherent structure
- clear hierarchy
- explicit missing inputs

## 5. Citation-Packaged Deliverable

Input:

- research findings with URLs
- target: decision memo

Expected result:

- readable prose
- claim-linked citation notes preserved
- unsupported claims removed or flagged
