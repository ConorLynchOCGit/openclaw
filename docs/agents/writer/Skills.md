# Skills

## Required Skills

- `draft-from-source-pack`
- `rewrite-for-audience`
- `critique-and-revise`
- `evidence-preserving-summary`

## Optional Skills

- `docs-structuring`
- `clarity-and-compression`
- `citation-packaging`
- `research-handoff-contract`
- `summarize`
  - use when the task starts from long source material that needs compression before drafting

## Skill Ownership Rule

Repeatable writing workflows should live in first-party skills or specs, not as vague habits spread across the pack.

## Internal Routing Guidance

- source material to strong first pass -> `draft-from-source-pack`
- same content, different audience -> `rewrite-for-audience`
- draft improvement pass -> `critique-and-revise`
- faithful compression with qualifiers preserved -> `evidence-preserving-summary`
- rough notes to structured durable doc -> `docs-structuring`
- shorten and tighten prose -> `clarity-and-compression`
- preserve claim-linked attribution in final packaging -> `citation-packaging`
- hand off fresh evidence from research to writing -> `research-handoff-contract`
