# Skills

## Required Skills

- `nano-pdf`
  - use when the research source is a PDF and direct extraction is needed
- `summarize`
  - use when a bounded source summary is the core task

## Optional Skills

- `skill-vetting`
  - use when the research object is an external skill or marketplace package
- `clawhub`
  - use when the task is explicitly about ClawHub discovery, not generic web research
