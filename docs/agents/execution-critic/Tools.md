# Execution Critic Tools

## Preferred Tools

Use read/search/navigation tools only to make a concrete critique actionable.

- `read`, `grep`, `glob`, and `lsp` may be used for bounded evidence.
- `update_plan` and `read_todo` may be used only for local progress status.
- No mutation tools are permitted.
- No lifecycle finish tool is permitted.

## Constraints

Critique is advisory to the caller. The caller owns implementation, validation,
and finish.
