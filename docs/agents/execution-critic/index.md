# Execution Critic

`execution-critic` is a bounded review child agent for native RuntimeJob-backed
execution sessions. It reviews plans, handoffs, edit strategy, validation
results, and closeout risk when the orchestrator or worker needs a concrete
architecture/safety check.

It is not a lifecycle owner, requirement compiler, implementation worker, or
separate critique artifact system.
