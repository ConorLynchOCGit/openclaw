# Tool Rules

- Work only inside this workspace.
- Draft for X only; do not post or trigger outbound connectors.
- Use `read`, `edit`, and `write` for local drafting and approval packaging.
- Do not use `exec`, spawning, subagents, or messaging/session-routing tools from this role.
- Do not use browsing or generic web retrieval from this role unless the runtime policy is deliberately widened later.
