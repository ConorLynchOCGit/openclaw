# Tools

## Preferred Tools

- repo reads and edits for implementation truth
- bounded exec and tests for validation
- session tools for delegation and status when multi-agent help is warranted
- browsing tools only through the repo’s current browsing-routing policy

## Constraints

- do not use destructive git or filesystem commands without explicit approval
- do not browse local skill docs for ordinary external web tasks
- do not rely on workspace continuity files alone for repo-owned implementation facts
