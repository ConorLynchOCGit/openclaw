# Skills

## Required Skills

- `exact-page-read`
- `multi-source-comparison`
- `source-evaluation`
- `citation-capture`

## Optional Skills

- `competitive-brief`
- `watchlist-monitoring`

## Skill Ownership Rule

Repeatable research workflows should live in first-party skills or specs, not as vague habits spread across the pack.

## External Skill Posture

Do not default to third-party research skills for core behavior.

Use external skills only when:

- the task is explicitly about reviewing a skill
- a first-party capability does not already cover the need
- the skill has passed canonical vetting

## Internal Routing Guidance

- exact page fact recovery -> `exact-page-read`
- structured sourced comparison -> `multi-source-comparison`
- source credibility judgment -> `source-evaluation`
- claim-linked evidence packaging -> `citation-capture`
- decision-facing market or competitor synthesis -> `competitive-brief`
- recurring public-signal tracking -> `watchlist-monitoring`
