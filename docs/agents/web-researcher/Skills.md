# Skills

## Required Skills

- no local skill should be read by default for ordinary public-web research
- ordinary URL and page-reading tasks should use the browsing tools directly through the runtime contract

## Optional Skills

- `clawhub`
  - only when the task is explicitly about internal skills or marketplace discovery
- `skill-vetting`
  - only when the browsing task is actually a skill-review workflow rather than generic web retrieval
