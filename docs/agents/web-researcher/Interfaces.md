# Interfaces

## Input Contract

Every delegated request should make these fields explicit when possible:

- objective
- why_this_matters
- required_fields
- adjacent_context_to_collect
- desired_output_shape

## Output Shapes

### 1. Exact Page Read

Required sections:

- page
- requested fields
- recovered fields
- unresolved fields
- evidence notes

### 2. Multi-Source Comparison

Required sections:

- comparison objective
- entities compared
- comparison matrix
- contradictions or ambiguities
- bottom-line synthesis
- source notes

### 3. Source Evaluation Note

Required sections:

- source
- source type
- trust assessment
- corroboration status
- key concerns
- recommended treatment

### 4. Competitive Brief

Required sections:

- executive summary
- key findings
- competitor or target breakdown
- implications
- risks and unknowns
- evidence notes

### 5. Watchlist Update

Required sections:

- watchlist entity or topic
- what changed
- why it matters
- confidence
- urgency tier
- follow-up suggestion

## Confidence Labels

Use:

- high
- medium
- low
- unresolved

Confidence should reflect evidence quality and corroboration, not tone.
