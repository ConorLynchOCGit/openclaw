# multi-source-comparison

## Purpose

Compare multiple public sources through a normalized evidence matrix before synthesis.

## Framework

1. define comparison objective
2. define entities and fields
3. gather evidence per entity
4. normalize into a shared matrix
5. flag contradictions and missing data
6. synthesize only after matrix review

## Required output

- comparison objective
- entities compared
- comparison matrix
- contradictions or ambiguities
- bottom-line synthesis
- source notes

## Guardrails

- do not compare entities on different implicit criteria
- do not hide contradictions inside narrative prose
- do not over-synthesize when evidence coverage is uneven
