# source-evaluation

## Purpose

Classify the trustworthiness and proper use of a source.

## Framework

Use:

- SIFT/lateral reading for web-native claims
- CRAAP-style checks for formal and institutional sources

Questions to answer:

- who is the source
- what kind of source is it
- how current is it
- what incentives or bias may shape it
- is the claim corroborated elsewhere
- should it be treated as primary, secondary, contextual, or weak evidence

## Required output

- source
- source type
- trust assessment
- corroboration status
- key concerns
- recommended treatment
