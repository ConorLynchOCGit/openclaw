# Deployment Topology

`deployment-topology` is the canonical project workspace for the OpenClaw VPS
deployment shape and its operational hygiene.

This project owns:

- one canonical repo / container / image posture
- runtime inventory and drift-prevention policy
- VPS git remote and GitHub CLI workflow
- PNPM/build hygiene for the live deployment environment
