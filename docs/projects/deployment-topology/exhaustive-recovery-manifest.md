# Exhaustive Recovery Manifest

This is the strict recovery manifest for functionality and durable operational
assets that were built before consolidation and then either:

- failed to move into the canonical repo
- survived only in live runtime or host state
- degraded into partial or hidden behavior
- were intentionally retired

This manifest is designed to drive the next restoration sprint directly.
