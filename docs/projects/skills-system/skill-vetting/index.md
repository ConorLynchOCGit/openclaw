# Skill Vetting

`skill-vetting` is the canonical workstream for reviewing external skills
before they touch the live workspace.

It owns:

- the quarantine review workflow
- the ClawHub search and acquisition posture
- the install / inspire / reject decision contract
- the risk-evaluation rubric and operator-facing outputs
