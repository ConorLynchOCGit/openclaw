# Skill Vetting Roadmap

## Phase 1 - Formalize the review lane

- create canonical docs
- create the repo-owned `skill-vetting` skill
- define quarantine and outcome contracts

## Phase 2 - Prove acquisition surfaces

- prove native search availability
- prove quarantine-safe acquisition availability
- prove temporary quarantine cleanup

## Phase 3 - Standardize outputs

- add durable operator-facing report templates
- normalize risk scoring and install conditions
- connect “inspire” outcomes to follow-on project/spec work

## Phase 4 - Broader system integration

- connect approved skills to allowlist and pack policy work
- connect rejected/high-risk skills to operator review or reporting surfaces
