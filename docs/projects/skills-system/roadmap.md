# Skills System Roadmap

## Phase 1 - Canonize the system lane

- create the top-level project workspace
- create the Skill Vetting workstream
- create the bundled repo-owned `skill-vetting` skill
- normalize ClawHub search/acquisition posture

## Phase 2 - Prove runtime availability

- verify which host/runtime surfaces expose native `openclaw skills` commands
- verify where `clawhub` CLI exists or should exist
- confirm quarantine acquisition works without touching the live workspace

## Phase 3 - Strengthen review outputs

- standardize operator-facing vetting reports
- add clear risk tiers and install conditions
- tie the outcome into future operator-review reporting where appropriate

## Phase 4 - Integrate with broader agent work

- connect vetted skills to agent skill allowlists
- connect “inspire” outcomes to follow-on project/spec generation
- connect approved install posture to future agent-pack population work
