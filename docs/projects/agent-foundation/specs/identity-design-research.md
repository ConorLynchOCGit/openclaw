# Identity Design Research

## Goal

Design `Identity.md` so it meaningfully powers each agent's function instead of
collapsing into a generic one-line role label.

## Research requirement

Use both:

- repo-local OpenClaw patterns
- external web/operator research relevant to real OpenClaw builds and agent use

## Questions the research must answer

1. what identity dimensions materially improve agent usefulness?
2. what should be durable versus runtime-configurable?
3. how should identity encode:
   - purpose
   - boundaries
   - collaboration posture
   - escalation posture
   - quality bar
   - failure modes
4. how should specialized agents differ from general helpers?

## Success criteria

- `Identity.md` becomes a meaningful durable control doc
- the writer agent and other specialized agents can be described with enough
  depth to guide real behavior
