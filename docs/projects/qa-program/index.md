# QA Program

`qa-program` is the canonical project workspace for OpenClaw QA evolution.

It brings together:

- the scenario-pack refactor direction
- frontier harness tuning and bakeoff loops
- scenario expansion planning

This workspace owns the project-level planning that was previously scattered
across `docs/refactor/qa.md` and loose files under `qa/`.
