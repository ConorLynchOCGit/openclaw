# Native Task Worker Agent Refactor Completion Matrix

Status: working audit, not final closeout.

Source spec:
`docs/projects/execution-platform/specs/native-task-worker-agent-refactor.md`

This matrix records current evidence from the repo and focused tests. It is not
a substitute for the final completion report. Items marked partial are the only
known nontrivial remaining gaps from this pass.

## Remaining Nontrivial Gaps

1. Item 36 / item 62: prompt/session-input duplication is still a caveat. The
   worker prompt is proven equal to native session input by hash, but the
   Execution Platform still stores a full worker-prompt artifact for optics and
   replay/readback. This must be classified as acceptable only if the native
   OpenClaw session input is not yet a sufficient exact replay/readback surface,
   or else reduced to refs/hash once native session input can carry that role.
2. Item 60 / item 64: focused proof is strong at the unit/simulated runner
   layer, but no new live Kimi worker proof was run in this pass. This remains
   a proof caveat because prior user direction said not to run broad/live proof
   on this run.
3. Item 13 is covered at the native task surface: the focused native task test
   proves two independent scout task calls can run together without sharing
   child session/run state. Full live model proof remains covered by the item
   60/64 caveat.
