# Maintenance Decisions

## Current decisions

1. the weekly maintenance guard should read canonical repo-owned control docs,
   not legacy workspace-only copies
2. the debt register should stay compact and action-oriented rather than
   preserving every historical closed item inline
3. the QA matrix should define maintenance verification boundaries without
   duplicating the full runbook
4. broader workspace-refactor analysis is retained as context, not as an
   automatic mandate for structural churn
