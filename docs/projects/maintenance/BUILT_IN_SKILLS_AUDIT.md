# Built-in Skills Audit

## Purpose

Provide a reusable audit template and a compact, evidence-based baseline for the built-in skills visible in this runtime.

This is an audit/control doc, not an activation plan. Do not add setup work here; record what is visible, what is blocked, and what still needs review.

## Verified skill roots

- `/app/skills`

Verified in this run by confirming the directory exists and listing visible `SKILL.md` files beneath it.

## Status classes

Use exactly these statuses:

- `usable now`
- `blocked by missing binary`
- `blocked by missing secret`
- `blocked by config/infra`
- `blocked by platform mismatch`
- `unclear / needs review`
- `low priority`

## Adoption notes for this slice

Adopted in this slice means:

- the skill was verified as usable from the current OpenClaw runtime surface
- a bounded real proof was run without changing risky runtime state
- the proof result is recorded here without implying broader host-wide availability

Adopted now:

- `node-connect`
  - bounded proof: non-mutating runtime diagnostic checks with `openclaw config get`
  - observed: `gateway.mode=local`, `gateway.bind=lan`, `gateway.remote.url` not set
- `weather`
  - bounded proof: `curl -s 'wttr.in/Nassau?format=3'`

Tested but not adopted from the OpenClaw runtime surface:

- `session-logs`
  - missing `jq` and `rg` on that surface during the proof turn
- `tmux`
  - missing `tmux` on that surface during the proof turn
