# X Manager Posting / Reply Handoff Outline

Purpose:

- define the handoff boundary between the standalone X / Twitter Manager and the human operator in the first proof

Draft handoff package:

- account
- item type
- final recommended draft
- core objective
- engagement posture
- risk level
- reply or quote target, if applicable
- voice rationale
- standing to post
- timing sensitivity
- why this is worth posting or replying to

Operator choices:

- approve
- revise
- hold_for_timing
- drop

Decision rule:

- `engagement_posture` remains the move type
- `final_recommendation` remains the action now
- for a valid original idea worth saving for later:
  - `engagement_posture: lead`
  - `final_recommendation: hold_for_timing`

First-proof rule:

- approval is the gate
- posting remains manual even after approval
