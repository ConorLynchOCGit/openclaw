# X Manager Memory / Context Outline

Purpose:

- define the minimum standalone memory/context pattern for the Phase 10.6 X / Twitter Manager

Layers:

1. Account voice memory

- preferred vocabulary
- disallowed tones
- recurring themes
- examples of “sounds right” vs “sounds wrong”

2. Current conversation memory

- active threads worth monitoring
- unresolved replies
- pending quote-post candidates
- last three replies and outcomes

3. Risk and sensitivity memory

- counterparties to treat carefully
- public-company / financing / regulatory sensitivity
- recent controversy notes
- current ratio state
- active narrative constraints

4. Performance memory

- hooks that earned quality replies
- formats that sounded too corporate
- timing patterns that worked
- phrasing to avoid repeating this week

First-proof rule:

- use memory to sharpen drafts and judgment
- do not let memory turn into automatic posting behavior
