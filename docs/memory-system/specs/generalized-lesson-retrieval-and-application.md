# Generalized Lesson Retrieval And Application

## Purpose

Generalized lesson retrieval and application proved that approved generic
guidance can retrieve through approved-only hybrid and apply usefully without
becoming broad semantic fallback.

That proof should now be absorbed into the shared retrieval and application
substrate.

## Current live posture

Approved generic:

- workflow lessons
- project rules
- unmet needs

retrieve through approved-only hybrid with family-relevant ranking boosts.

Current production posture still keeps:

- hybrid retrieval as the default
- semantic routing narrow and family-gated
- prompt-layer application bounded and explicit

## What this proved

The generalized retrieval/application work proved:

- generic memories can rank usefully with canonical field overlap
- approved-only retrieval works for broader guidance families
- prompt-time application can stay guidance-only or recommendation-only
- broad semantic retrieval is not required for useful generic family behavior

## What flattening will absorb into shared substrate

The flattening phase should absorb the generalized-family retrieval advantages
into:

- `/memory-system/specs/retrieval-feature-framework`
- `/memory-system/specs/behavior-profile-layer`

That means:

- feature-based ranking instead of family-specific SQL growth
- explicit application profiles instead of prompt-only policy

## What remains intentionally family-specific

- workflow lessons and project rules remain guidance-only
- unmet needs remain recommendation-only
- semantic routing remains family-gated

## What future family work must not re-implement locally

Future family slices must not add:

- a new family-specific ranking forest
- a new prompt-only application loop
- a new one-off matched-field vocabulary when the shared feature framework can
  express the same concept

## Next sequencing note

The next step is not broader generalized-family special casing. The next step is
flattening retrieval selection and application policy across the already landed
families.
